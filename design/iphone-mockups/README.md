# iPhone mockups

The screen mockups of the iPhone companion, drawn from Parker's real tokens
(Vercel Day/Night, the to-do colors, the Lucide glyphs, Geist Mono).

- `gen.py` — writes one `.dc.html` artboard per screen plus `canvas.json`
  (positions, connector notes, the flow map).
- The artboards are seeded into a Claude Design canvas:
  https://claude.ai/code/artifact/843d9b1e-b24c-4e4b-a035-78b6ae2c9e93

All sample content is fictional.
