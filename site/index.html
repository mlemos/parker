Parker is a fast, minimal Mac editor for notes, code and markdown — the scratchpad you keep open while working with AI: long prompts, plans and quick snippets, without the weight of Notes, VS Code and friends.

Work with your AI

Let your AI into your notes.

Your notes are plain files in a folder you chose — so Claude Code, Codex, Cursor or any agent can already read and write them. No plugin, no API key, nothing to integrate. Point it at the folder and it's in.

Parker closes the loop from its side: when your agent rewrites a note, the open tab reloads live and marks exactly which lines changed — never over edits you haven't saved.

  • Draft the prompt here, let the agent answer into the same file
  • Hand it a task list and watch the checkboxes flip
  • Git backup underneath: every AI edit is a commit you can roll back
$ claude
 
> update my backlog in ~/Documents/Parker

Built to get out of your way.

Your data, your rules

Just a folder of plain files.

Parker always writes straight to disk — .md, .txt and code, in a folder you own. Never a database, never a cloud you don’t control. Sync it however you like — iCloud, Dropbox, whatever — Parker stays completely sync-agnostic.

Want it all in git? It’s built in. Flip on git backup and every save is committed and pushed — fully versioned, with a history you can roll back. A safety net on top of your files, never where they live.

  • Always on disk — open your notes in any editor, anytime
  • No account, no lock-in, no telemetry
  • Optional git backup: versioned, integrated, one switch
