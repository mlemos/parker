For AI agents

Agent edits. Parker shows.
You control.

Your notes are plain files, so your agent can already write them. The Parker skill teaches it the rest: your folder, your to-do marks, edits that don't damage a note, and decisions handed back to you.

Set it up What it teaches
In the note you have open

Every change in plain sight.

The agent writes. Parker reloads the note and marks the lines it changed. Type at the same moment and Parker asks which version to keep. The decisions stay yours, written in the note.

  • Changed lines marked until you type
  • Tasks in your own to-do marks
  • Decisions handed back to you
  • Your lines never rewritten

Three steps, once.

Install the skill, let it find your notes, and write your own rules down.

  1. 1

    Install the skill

    Claude Code

    In Parker, open Settings › AI Agents and click Install. Or from a terminal:

    mkdir -p ~/.claude/skills/parker && curl -fsSL https://getparker.dev/agents/SKILL.md -o ~/.claude/skills/parker/SKILL.md

    The Code tab of the Claude desktop app reads the same folder.

    Claude app — desktop, Cowork, claude.ai

    Download parker-skill.zip (or save it from Settings › AI Agents), then in Claude open Customize › Skills, click +, choose Upload a skill and pick the file.

    Needs Code execution turned on in Claude's Settings › Capabilities. Skills turned on there work in Cowork too.

    Other agents

    The skill is one Markdown file: SKILL.md. Put it wherever your agent reads its instructions, or tell the agent to read it before it works in your notes.

  2. 2

    Let it find your notes

    The skill looks where Parker keeps them: the folder chosen in Parker's Settings, or ~/Documents/Parker. There is nothing to configure. An agent that runs somewhere it can't see your Mac's files says so instead of guessing.

  3. 3

    Write your rules in a README

    A README.md at the root of your notes folder holds your own conventions. The skill tells agents to read it before they write, and to follow it where the two differ. Parker can start one for you in Settings › AI Agents; the same starter is at the end of the skill below.

What the skill teaches.

One Markdown file, about 140 lines. Read SKILL.md · on GitHub

Where your notes are

The folder set in Parker, or ~/Documents/Parker. It reads your README before it writes, and says so when it can't reach the folder.

Your to-do marks

The eight states Parker renders, from /TODO to /CANCEL, four priority levels, and where a new task goes.

Edits that don't damage

Re-read before writing, change only what it means to, never fight the note you have open, never touch git history.

Notes you can scan

One line per item, one topic per line, Markdown that reads well raw. No walls of text.

Decisions handed back

An /ATTN with the question, the options lettered and a recommendation, so you decide in the note.

Your words stay yours

It answers below your lines and signs its own with C:. A guess ends in (???).
